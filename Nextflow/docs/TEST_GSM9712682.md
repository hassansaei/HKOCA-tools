# Test dataset: GSM9712682

GEO **GSM9712682** / **GSE329881**: day-12 wild-type UB organoids (Parse Evercode / TrailMaker). Used to validate the Nextflow workflow.

See [`use_cases/GSM9712682/README.md`](../use_cases/GSM9712682/README.md) for full metadata and the slim evidence pack.

Inputs for a local re-run: converted h5ad (or GEO RDS), `sample_info.template.csv`, GRCh38 GTF, and optionally the HKOCA atlas + scPoli model for projection. CellBender is skipped for this deposit.
